# music/

103 αρχεία MIDI κατεβασμένα στις 2026-09-21 από
<https://www.mfiles.co.uk/midi-original.htm> («Original MIDI Music»).

## Τα αρχεία δεν είναι στο repo

Το `.gitignore` εξαιρεί το `music/*.mid`. Αυτό το README είναι ό,τι μπαίνει
στο git. Για να τα ξανακατεβάσει κάποιος: `./music/fetch.sh`.

## Γιατί

Οι όροι του mfiles ([licensing.htm](https://www.mfiles.co.uk/licensing.htm))
λένε ότι το υλικό δημοσιεύεται

> ως δωρεάν υπηρεσία, κυρίως για προσωπική και ιδιωτική χρήση ατόμων

και ότι άτομα, φιλανθρωπικοί και εκπαιδευτικοί φορείς μπορούν να το
χρησιμοποιούν **αυστηρά για μη εμπορικούς σκοπούς**. Το υποσέλιδο κάθε σελίδας
γράφει «copyright © 1999-2026 Music Files Ltd. All rights reserved.»

Το `github.com/vaspervnp/CPCArt` είναι δημόσιο. Commit των `.mid` εκεί είναι
αναδημοσίευση, όχι ιδιωτική χρήση — γι' αυτό μένουν εκτός.

## Αν προορίζονται για το Habitat

Η ίδια σελίδα αναφέρει ρητά τα computer games ως περίπτωση που θέλει άδεια, και
η Music Files Ltd δίνει άδειες γι' αυτό. Οπότε:

- **Ως αναφορά** — μελέτη δομής, ενορχήστρωσης, τέμπο για τη μουσική AY: εντάξει
  τοπικά, καμία άδεια δεν χρειάζεται.
- **Μέσα στο παιχνίδι**, ακόμα και μεταγραμμένα σε AY: χρειάζεται άδεια, γιατί η
  σύνθεση προστατεύεται ανεξάρτητα από τη μορφή αρχείου. Επικοινωνία μέσω της
  σελίδας licensing.
- **Εναλλακτικά** για δωρεάν υλικό: συνθέσεις σε public domain, ή κομμάτια με
  ρητή άδεια CC.
