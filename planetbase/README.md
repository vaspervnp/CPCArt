# Planetbase — colony sim για Amstrad CPC 6128, Mode 0

Sprites 16 χρωμάτων, παραγμένα **εξ ολοκλήρου από κώδικα** (γεωμετρία + ASCII art).
Τίποτα δεν ζωγραφίζεται σε εξωτερικό πρόγραμμα και τίποτα δεν φορτώνεται από έτοιμα PNG.

```
python3 tools/make_sprites.py                 # τα ξαναφτιάχνει όλα
python3 tools/make_sprites.py --anim-frames 2 # + δεύτερο frame πληρότητας
```

Το script αποτυγχάνει αν κάποια από τις επαληθεύσεις δεν περάσει, οπότε ό,τι
βρίσκεται στο `build/` είναι εξ ορισμού συνεπές με τις προδιαγραφές.

| Αρχείο | Περιεχόμενο |
|---|---|
| `tools/make_sprites.py` | γεωμετρία, κωδικοποίηση Mode 0, επαληθεύσεις, έξοδος |
| `tools/palette.py` | η παλέτα — **ένα σημείο ορισμού** (FW numbers, RGB, χαρακτήρες ASCII) |
| `tools/icons.py` | ASCII art: εικονίδια δωματίων και φιγούρα αποίκου |
| `build/sprites/sprites.asm` | πηγαίος κώδικας RASM, γραμμικά δεδομένα, με ASCII σχόλιο ανά γραμμή |
| `build/sprites/sprites.bin` | τα ίδια bytes σε raw binary |
| `build/sprites/sprites_map.txt` | offset και μέγεθος κάθε sprite μέσα στο `.bin` |
| `build/sprites/preview/sheet.png` | όλα τα sprites με πλέγμα και ετικέτες |
| `build/sprites/preview/composite.png` | πλήρης θόλος: 4 quads ring + εικονίδιο + επίπεδο 3 |
| `build/sprites/preview/*.png` | ένα PNG ανά sprite |

Οι προεπισκοπήσεις σχεδιάζονται **αποκωδικοποιώντας τα παραγόμενα bytes**, όχι από
την ενδιάμεση εικόνα — έτσι επαληθεύουν και την ίδια την κωδικοποίηση. Κάθε pixel
Mode 0 αποδίδεται 8×4 πραγματικά pixels (αναλογία 2:1, κλίμακα ×4).

## Διάταξη μνήμης (3328 bytes)

Το μπλοκ φορτώνεται σε **διεύθυνση πολλαπλάσιο του 256** — το γέμισμα πριν από το
`flip_mode0` είναι ήδη υπολογισμένο, ώστε ο πίνακας να πέφτει σε σελίδα.

| Offset | Ετικέτα | Bytes | Δείκτης |
|---|---|---|---|
| `#0000` | `dome_quads` | 2048 | `dome_quads + QUAD_BARE*bare + corner*256` (corner: nw, ne, sw, se) |
| `#0800` | `room_icons` | 256 | `room_icons + type*32` |
| `#0900` | `occupancy` | 480 | `occupancy + level*96` |
| `#0AE0` | `corr_h`, `corr_v` | 64 | — |
| `#0B20` | `palette_fw` | 16 | 16 firmware colour numbers, pen 0..15 |
| `#0C00` | `flip_mode0` | 256 | `ld h,flip_hi : ld l,a : ld a,(hl)` |

Με `--anim-frames 2` τα επικαλύμματα διπλασιάζονται (960 bytes, σύνολο 3840) και ο
δείκτης γίνεται `occupancy + frame*OCC_FRAME + level*OCC_SIZE`.

## Γεωμετρία

Θόλος με πλήρη δακτύλιο: **32 × 64** pixels (οπτικά 64×64), κέντρο στο (16, 32).
Παραμετρικά μέσω `DOME_D=48` και `CORRIDOR_W=8` στο `make_sprites.py`.

Ο θόλος αποθηκεύεται σε 4 τεταρτημόρια 16×32 που περιέχουν **και** το κομμάτι του
διαδρόμου, σε δύο παραλλαγές (`_ring` / `_bare`). Έτσι όλα τα blits είναι αδιαφανή:
χωρίς mask, χωρίς επικαλύψεις. Στα `_bare` ο διάδρομος γίνεται φόντο **πριν** από
τον υπολογισμό των άκρων.

Θέσεις μέσα στο πλαίσιο: εικονίδιο στο (12, 14), επικάλυμμα πληρότητας στο (10, 26).
Και τα δύο βρίσκονται εξ ολοκλήρου σε pixels δαπέδου που δεν είναι άκρη — το script
το επαληθεύει.

## Επαληθεύσεις

Τρέχουν σε κάθε build· οποιαδήποτε αποτυχία σταματά την παραγωγή.

1. `encode_mode0` — οι δοκιμές των προδιαγραφών και `encode(decode(b)) == b` για 256 bytes
2. `flip(flip(b)) == b` για 256 bytes
3. κάθε sprite έχει ζυγό πλάτος και ακριβώς `(w/2) * h` bytes
4. τα 4 τεταρτημόρια συναρμολογημένα ταυτίζονται pixel-προς-pixel με το πλαίσιο 32×64
5. `quad_ne` = οριζόντιο καθρέφτισμα του `quad_nw`, `quad_sw` = κάθετο (ring και bare)
6. εικονίδιο και επικάλυμμα: μέσα στον θόλο, όχι σε άκρη, χωρίς επικάλυψη μεταξύ τους
7. το `sprites.bin` ταυτίζεται byte-προς-byte με τα δεδομένα του `sprites.asm`
   (το script ξαναδιαβάζει το `.asm` που μόλις έγραψε)
8. σύνοψη με πλήθος sprites και bytes ανά κατηγορία

## Τι μένει

Η ενότητα 7 των προδιαγραφών (`colony_data.asm`: `draw_dome_full`, `blit_opaque`,
`R_RING`, κατάργηση του `sprite_bases`) αφορά τον κώδικα Z80 και δεν είναι μέρος
αυτού του φακέλου — εδώ παράγονται μόνο τα δεδομένα που θα καταναλώσει.
